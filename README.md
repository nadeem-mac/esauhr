# Leave Desk

KSA-built HR vacation tracking platform. React + Vite + Supabase + Netlify.

## Local development

```bash
npm install
cp .env.example .env.local   # then fill in Supabase URL + anon key
npm run dev
```

## Deployment

Netlify auto-deploys from `main` branch. Build command: `npm run build`. Publish dir: `dist`.
